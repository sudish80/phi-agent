# Example Skill

A template skill. Skills are loaded from `workspace/skills/<name>/SKILL.md`.
The content of this file is injected into the system prompt when the skill is active.

## What this skill does
- Demonstrates the skill system structure
- Provides a pattern for creating new skills

## Instructions
- Follow the SKILL.md convention from openclaw
- Each skill owns its domain-specific instructions
- Skills are discovered automatically at startup
